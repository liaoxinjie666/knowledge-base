Python 编程语言简介

Python 是一种高级、解释型、通用编程语言，由 Guido van Rossum 于 1991 年首次发布。Python 的设计哲学强调代码的可读性和简洁性。

Python 的主要特点：
1. 语法简洁清晰，使用缩进来定义代码块
2. 动态类型系统，变量不需要预先声明类型
3. 自动内存管理（垃圾回收机制）
4. 支持多种编程范式：面向对象、函数式、过程式
5. 拥有丰富的标准库和第三方库生态系统

Python 广泛应用于以下领域：
- Web 开发（Django、Flask、FastAPI）
- 数据科学与机器学习（NumPy、Pandas、Scikit-learn、PyTorch）
- 自动化脚本与系统运维
- 网络爬虫（Scrapy、BeautifulSoup）
- 人工智能与深度学习（TensorFlow、PyTorch）

RAG 技术简介

RAG（Retrieval-Augmented Generation，检索增强生成）是一种结合了信息检索和文本生成的技术。

RAG 的工作流程：
1. 用户提出问题
2. 系统从知识库中检索与问题相关的文档片段
3. 将检索到的文档片段和用户问题一起发送给大语言模型
4. 大语言模型基于检索到的上下文生成回答

RAG 的优势：
- 减少大语言模型的"幻觉"问题
- 回答可以追溯到具体来源
- 知识可以实时更新，无需重新训练模型
- 保护私有数据，不需要将敏感信息发送给第三方

向量数据库简介

向量数据库是专门用于存储和检索高维向量的数据库系统。在 RAG 系统中，向量数据库用于存储文档的向量化表示。

常见的向量数据库包括：
- ChromaDB：轻量级，纯 Python 实现，适合小型项目
- Milvus：分布式架构，适合大规模生产环境
- Pinecone：全托管云服务，使用简单
- FAISS：Facebook 开源的向量检索库，性能优秀

向量检索的基本原理是计算查询向量与数据库中所有向量的距离（如余弦相似度、欧氏距离），返回最相似的 Top-K 结果。
